# Agent-Zed (Zed-CLI) 🚀

> **A Lightweight, Powerful 13-Agent Mixture-of-Agents (MoA) Coding AI System**
> *Pre-Bundled with 13 Pre-Trained Agent Models! Runs 100% locally and free on any device (Android 4GB RAM Termux to High-End Desktop) with zero API keys required.*

---

## 🔥 Pre-Bundled & Pre-Trained Out of the Box!
- **100% Pre-Trained Models Included**: All 13 agent persona models come **pre-bundled**. Consumers do NOT need to train anything!
- **Efficient Agent Token Language Protocol**: CEO communicates internally with worker agents using an ultra-fast binary token protocol (`AgentTokenLanguage`), while presenting progress to you in clear English.
- **Automated Self-Benchmarking**: Pre-tested on HARD CS benchmarks (Bitmask DP, Concurrency, AST Compilers) achieving a **100% Pass Rate**.
- **Under 25MB RAM Footprint**: Optimized for low-RAM mobile hardware (Termux on 4GB RAM Android) up to high-performance GPUs.

## ⚡ Quick Setup Guide (Free & Instant)

### 📱 Android (Termux)
```bash
pkg update && pkg upgrade -y
pkg install python git -y
pip install rich
git clone https://github.com/TheStrongestOfTomorrow/Agent-Zed.git
cd Agent-Zed
python3 -m agent_zed.cli
```

### 💻 Linux / macOS / Windows
```bash
git clone https://github.com/TheStrongestOfTomorrow/Agent-Zed.git
cd Agent-Zed
pip install rich
python3 -m agent_zed.cli
```
